# TingXie HERO

Technical assignment for the Back-End Developer recruitment process.

> Status: In Development  
> Development Period: September 1–5, 2026

## Overview

TingXie HERO is a student-focused handwriting practice application.

The main workflow is:

    Select Lesson
        ↓
    Capture Handwriting
        ↓
    Submit Image
        ↓
    AI-Assisted Grading
        ↓
    Store Result
        ↓
    Display Score & Correction Feedback

## Planned Stack

- Next.js
- Tailwind CSS
- Supabase
- Gemini
- Vercel

The final architecture may change as technical research and implementation
progress.
